# DS AUTO 면접 리허설

최신 DS AUTO 발표 12장을 바탕으로 고객 미팅 RP 16장면과 일반 채용 면접 13문항을 이어서 연습하는 정적 웹앱입니다. 총 29장면이며 `index.html` 하나로 동작합니다. 빌드나 API 키가 필요하지 않습니다.

## 연습 방법

- **전체**: 대표·COO와 발표 및 질의응답을 진행한 뒤, 고객 역할 종료 화면을 거쳐 일반 면접으로 전환합니다.
- **RP만 / 일반 면접만 / 장면 하나**: 원하는 구간에 집중할 수 있습니다.
- **선택형**: 답의 순서를 섞고, 각 선택에 미리 작성된 반응과 피드백을 제공합니다.
- **직접 답변**: 모든 환경에서 쓸 수 있습니다. AI를 사용할 수 없으면 답변을 남기고 기준별 체크와 본인이 선택한 점수로 자가평가합니다. 자동 채점처럼 표시하지 않습니다.
- **꼬리질문**: 답변의 수준과 위험 신호에 따라 달라지며 장면당 두 번까지 답할 수 있습니다. RP 후 자기평가 질문은 방금 RP의 보완 장면을 짚습니다.
- **복기**: RP·일반 면접 점수, 평가 방식별 개수, 항목별 점수와 위험 신호를 확인합니다. 보완 장면만 재연습하거나 답변·대화·피드백을 JSON으로 내려받을 수 있습니다.
- **저장**: 코스, 진행, 답변 초안과 복기를 브라우저 `localStorage`에 저장합니다. 새로고침 후 ‘저장한 연습 이어하기’를 누릅니다. 저장 공간이 차단되면 현재 화면의 연습은 계속할 수 있습니다.

점수는 75점 이상, 심각한 위험 신호 2개 미만이라는 **연습 기준**입니다. 실제 채용 결과를 예측하지 않습니다. 자가평가 점수는 AI 평가와 분리해 표시합니다. 재도전은 최신 답변 점수로 반영하며 최초 점수도 복기 데이터에 남깁니다.

## 최신 장표 매핑

2026-11-03의 12장 교정본을 기준으로 합니다. PDF의 이미지 자체를 복제하지 않고 각 장의 제목·메시지·질문을 게임에 반영했습니다.

| 장표 | 메시지                                                    | RP 장면                    |
| ---- | --------------------------------------------------------- | -------------------------- |
| 1–2  | 영업기회를 조직의 자산으로, 문제 진단과 검증 범위 합의    | 오프닝                     |
| 3–4  | 실제 상담 고객의 경험, 반복 설명과 최종 구매              | 고객 경험 및 이탈 이유     |
| 5    | 고객 맥락 단절이 고객 경험과 내부 업무 모두에 미치는 영향 | 같은 단절, 다른 문제       |
| 6    | 개인 기록이 팀의 이력과 조직 자산으로 이어지는가          | 자산화 및 현황 진단        |
| 7    | 회사 이력, 다음 행동, 관리 판단                           | 해결 방향                  |
| 8    | 담당자·관리자 화면 예시                                   | 가상 수치와 고객 기준 구분 |
| 9–10 | 사업 확장, 판매 이후 정비·매입·재구매                     | 단계적 확장                |
| 11   | 자동차 업계 도입, 한샘·GC녹십자웰빙 공개 성과             | 사례 및 적합성 반박        |
| 12   | Connect·Prove·Scale, 45분 실무 미팅                       | 다음 단계 합의             |

데이터·고객 맥락의 단절이 **공통 원인**입니다. 고객의 반복 설명이 내부 문제의 원인이라는 설명은 감점합니다. 고객에게는 반복 설명, 영업에는 확인 지연·후속 누락, 관리자에게는 취합·코칭·예측의 어려움으로 드러납니다.

## 내용의 사실 경계

- 자동차·모빌리티 사례는 롯데렌탈·현대오토에버·현대모비스의 공개 도입 범위로 설명합니다. 과거 게임의 Harwoods 중심 구성은 사용하지 않습니다.
- 한샘 약 90%는 오픈 한 달여 후 **RD의 담당 고객 후속 관리 비율**, 약 10%는 **본사 영업사원(TR)의 전체 업무 시간 절감**입니다.
- GC녹십자웰빙 95%는 도입 1년 후 **월 활성 사용자 비율**, 50%는 **영업 인수인계 및 거래처 행정 업무 시간 단축**입니다.
- 공식 사례 링크는 게임의 ‘최신 12장 흐름과 사례 출처’에서 확인합니다. 타사 수치를 DS AUTO의 목표나 보장 성과로 바꾸지 않습니다.
- 사흘 재연락, 엑셀 취합, 대표가 감으로 말하는 재구매 30% 등은 **게임용 가상 고객 설정**입니다. 실제 DS AUTO 운영의 확인된 사실로 설명하지 않습니다. Salesforce 미계약 첫 미팅 역시 면접 과제의 전제입니다.
- 일반 면접의 예시 답변은 문장 구조를 연습하기 위한 것입니다. 실제 고객명·금액·기간·분모·본인 기여는 본인의 사실로 채워야 합니다. COREPRESS는 **6인 교육용 가상 팀 PoC**이며 실제 고객의 상용 구축이 아닙니다.
- 가격은 고정된 달러 금액을 외우게 하지 않고 사용자·범위·구축·연동·운영 비용 및 최신 공식 가격 확인 절차로 답하도록 합니다.

## AI 평가와 데이터

Claude Artifact에서 `window.claude.use("sample")` 기능을 제공하는 경우에만 기존 AI 평가를 사용합니다. Vercel과 일반 브라우저에는 이 기능이 없으므로 선택형 또는 직접 답변의 자가 점검으로 동작합니다. AI가 없다고 답변 입력 기능을 숨기지 않습니다.

AI 평가를 선택하면 답변과 관련 대화·평가 기준이 해당 기능으로 전달됩니다. 실패·거부·45초 시간 초과 시 답변을 보존하고 재제출 또는 자가 점검을 제공합니다. AI 응답이 잘못된 형식이면 0점으로 처리하지 않습니다. 별도 서버나 공개 API 키를 추가하지 않았습니다.

저장된 답변은 이 브라우저에서만 유지됩니다. 공유 기기에서는 해당 사이트의 저장 데이터를 지워 기록을 제거할 수 있습니다. 내려받은 복기는 개인 답변을 포함하므로 필요한 범위에서 공유하세요.

## 로컬 실행과 검증

저장소 루트에서:

```bash
python3 -m http.server 8123 --directory apps/ds-auto-roleplay
```

브라우저에서 `http://localhost:8123`을 엽니다. `index.html`을 직접 열어도 동작하지만, 파일 URL의 저장 동작은 브라우저에 따라 다를 수 있습니다.

추가 패키지 없이 Node.js로 시나리오, 점수, 꼬리질문, 사례 경계와 DOM 연결을 검증합니다.

```bash
node --test apps/ds-auto-roleplay/tests/roleplay.test.cjs
```

## Vercel 배포

1. Vercel에서 이 저장소를 Import합니다.
2. 개발 브랜치 `claude/sharp-pascal-7zztmi`를 선택합니다. 기본 브랜치는 `master`이므로 개발 내용이 자동으로 포함되지 않습니다.
3. **Root Directory**를 `apps/ds-auto-roleplay`로 지정합니다.
4. Framework Preset은 `Other`, Build Command와 Output Directory는 비워 둡니다.
5. 해당 브랜치의 Preview 배포를 생성합니다. 프로덕션 브랜치 변경이나 기본 브랜치 병합은 별도 작업입니다.

저장소의 파일과 기존 Claude Artifact 링크는 별개입니다. GitHub 파일을 수정해도 기존 Artifact 사본은 자동 갱신되지 않습니다.


## ChatGPT 안에서 GPT 평가 받기

설치·연결·실행과 검증 명령은 [ChatGPT 앱 README](chatgpt-app/README.md)를 참고한다.
